# Product: Verbatim

Derived from the owner-approved design documents (`docs/00-brief.md`, `docs/05-ui-design.md`, `docs/proto/paper.html`); no separate interview. Those documents win over this file.

- **What it is:** a VST3 audio effect for Windows. The user types text; the text deterministically generates an effects chain. Same text, same sound.
- **Who uses it:** music producers inside a DAW, mid-session, often with headphones on and a mix playing.
- **Surface mode:** Operate. The editor is a tool used while listening; scanability and native-feeling controls outrank expression.
- **Visual world (fixed):** a typewriter machine. Mint enamel body, cream paper, two-colour ribbon (ink and red), round latching keys. Tokens in `docs/05-ui-design.md` section 4.
- **Principles from the owner:** icon-led, minimal text, no on-screen instructions, simple and elegant, built around the producer's path from first load to finished sound.
- **Deliberately absent:** preset browser, per-effect bypass, tabs, a manual, tooltips that explain grammar.
